# 银行反诈公益短视频

## 一、作品简介

本作品以防范电信网络诈骗为主题，通过老年客户遭遇冒充平台客服诈骗、银行工作人员及时识别并进行劝阻的故事，宣传电信网络诈骗防范知识。

## 二、作品信息

- 作品类型：AI辅助制作公益宣传短视频
- 主题：防范电信网络诈骗
- 视频时长：约1分48秒
- 视频形式：二维公益宣传动画

## 三、AI工具使用情况

### ChatGPT
用于剧本构思、剧本撰写、分镜设计，以及人物、场景和视频生成提示词设计。

### 即梦AI
用于人物立绘、场景图片以及分段视频画面的生成。

### MiniMax
用于人物对白及视频配音生成。

### 人工制作
对AI生成内容进行筛选、修改、调整和剪辑，并完成字幕、音频、画面衔接及最终审核。
